# VANTERA — Professional Frontend

## اجرا
1. ZIP را استخراج کنید.
2. پوشه پروژه را در VS Code باز کنید.
3. فایل `index.html` را در مرورگر باز کنید؛ برای توسعه از Live Server استفاده کنید.

## امکانات
- شش صفحه فارسی و راست‌چین با فونت Vazirmatn
- تم مشکی و طلایی، هدر شیشه‌ای و طراحی واکنش‌گرا
- اسلایدر صفحه اصلی با کنترل قبلی/بعدی
- منوی موبایل، انیمیشن ورود هنگام اسکرول و شمارنده‌های متحرک
- فیلتر نمونه‌کارها و فرم نمایشی
- تصاویر SVG محلی در پوشه images؛ برای تصاویر گرافیکی نیازی به دانلود جداگانه نیست.

## توجه
اطلاعات تماس، نمونه‌کارها و آمار فعلی نمونه هستند. فرم تماس هنوز به سرور متصل نیست. فونت Vazirmatn از Google Fonts بارگذاری می‌شود؛ برای استفاده کاملاً آفلاین باید فونت را محلی اضافه کنید.
